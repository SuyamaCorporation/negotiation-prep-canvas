## 交渉前準備キャンバス

BATNA・ZOPA・優先度マトリクス・ポジション設定の4ステップを埋めると交渉スクリプトのたたき台を生成し、交渉に自信を持って臨むための思考整理ツール。

### 機能
- Step 1: 自分の BATNA と相手の BATNA 推測を入力
- Step 2: 自分と相手の許容レンジを入力し ZOPA（合意可能ゾーン）を Canvas でビジュアライズ
- Step 3: 交渉条件（価格・支払いサイト等）ごとに重要度×譲歩可能性をクリックで設定する優先度マトリクス
- Step 4: 開始ポジション・ターゲット・ボトムラインを入力
- 完了時に交渉スクリプトたたき台（Markdown）を生成表示・クリップボードコピー
- 複数案件を名前付きで保存・切り替え・削除
- localStorage による案件データの永続保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas API（ZOPA ビジュアライゼーション）
- Clipboard API（スクリプトのコピー）
- localStorage（案件データ保存）
